Activar el guardado automático

Para guardar desde el móvil sin copiar nada, la app necesita una clave de acceso de GitHub. Se guarda solo en este dispositivo y solo puede editar los archivos de este repositorio (no toca tu Telegram ni nada más). Puedes anularla cuando quieras.

Cómo crearla (una sola vez):
  1. Abre esta página de GitHub (estando con tu sesión iniciada).
  2. Token name: selector one piece. Expiration: 1 año.
  3. Repository access → Only select repositories → elige vigilante-one-piece.
  4. Permissions → Repository permissions → Contents → Read and write (lo demás déjalo en No access).
  5. Abajo, Generate token y copia el código (empieza por github_pat_).
